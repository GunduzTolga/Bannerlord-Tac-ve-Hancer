## Q1. Which cheat/editor mods are the most popular, and what is their current status (v1.3.x / v1.4.x)?

### Takeaway
The original **Bannerlord Cheats** (NicoWaves) is still the most downloaded cheat mod, but it was last updated in July 2023 and is no longer maintained. Its community fork **Bannerlord Cheats Reload** (Ko4evnik, v1.3.15, partly works on 1.4.7/1.4.8) and the Steam-only **UFO's Cheat Mods Bundle [1.4.8]** have taken its place. Several projects are actively maintained in 2026:
- **BannerWand Cheats**: MCM trainer with per-faction targeting.
- **Bannerlord.GameMaster (BLGM)**: console commands, open source.
- **Commander**: Gauntlet GUI built on BLGM.
- **Character Reload Fix**: encyclopedia-button editor, e1.4.5.

**Detailed Character Creation** remains the most-endorsed editor mod overall. Dedicated mods for teleport, rename, time, aging and encyclopedia reveal are small, single-purpose, and mostly from 2026.

### Inferences
- **Popularity ranking.** By all-time downloads and endorsements: DCC, then Bannerlord Cheats (original), then Character Export Import, then the Character Reload family, then Bannerlord Cheats Reload. By 2026 activity and compatibility, the leaders are Cheats Reload / UFO Bundle (Steam), Character Reload Fix, BannerWand and BLGM + Commander.
- **Fragmented market.** Most users need two or three mods: a cheat mod, an editor and a time or teleport mod. This favours an all-in-one design.
- **Fork-and-patch pattern.** The ecosystem keeps repeating one cycle: the original author abandons a mod, then a fork patches it per game version. Cheats became Cheats Reload, then the UFO Bundle. Character Reload became Character Reload Fix. Users are left waiting on "please update" threads for every TaleWorlds patch. A mod that tolerates version changes well (see Q4) is the main competitive advantage.
- **Teleport and rename have no strong maintained winner.** No high-endorsement, maintained mod exists for either. Users use vanilla cheat mode or full editors (BLGM, Character Reload) for these.

### Gaps
- I could not see a v1.4.x-specific file for Bannerlord Cheats Reload. The page shows v1.3.15.0, and 1.4.x compatibility rests only on user comments.
- I did not verify which Bannerlord versions BannerWand's current file targets. The tags and file names were not captured.
- Steam subscriber counts for Character Reload, DCC, Character Manager and Commander on the Workshop were not captured. Steam rate-limited WebFetch, and the browser listing does not show counts.
- The WebFetch of the Steam "Cheats" page returned "removed from the community" and "incompatible" notices. These are probably hidden Steam template strings, so I am not treating them as fact.
- I found no Reddit thread from 2025–2026 ranking cheat or editor mods. Searches returned only SEO roundups.

## Q2. What exact features do they offer, and which features are most requested? (Per-mod feature lists + consolidated de-duplicated list)

### Takeaway
Two feature sets exist today:
- **The "Bannerlord Cheats" lineage**: about 116 MCM sliders and toggles covering map, combat, party, clan, characters, kingdom, XP, siege, army, settlement, smithing and workshops, plus per-screen hotkeys.
- **The "editor" lineage** (Character Reload, BLGM/Commander): direct edits to any hero, clan, kingdom or settlement. This covers name, appearance, age, skills, perks, traits, relations, ownership, buildings, marriage, pregnancy and banner.

No single mod combines both well. Requested features include:
- rename (settlements especially)
- faster map travel or teleport
- higher time speed
- age freezing
- relation editing
- staying current with game patches (the most requested by far)

### Inferences
- An all-in-one mod needs to cover three layers:
  - global rule modifiers (the Cheats/BannerWand sliders)
  - direct object editors (Character Reload/BLGM/Commander)
  - map and time utilities (teleport, speed, waypoints)
- No current mod covers all three. Commander comes closest for editors but has no cheat sliders, teleport or time control.
- **Unclaimed niches**:
  - Party renaming, and a clean "rename anything" across party, clan, kingdom and settlement from one UI. Only BLGM covers kingdom rename, and only by console.
  - A maintained teleport that handles towns and settlements correctly. The 10005 mod "doesn't correctly teleport you to towns".
  - Fog/visibility reveal beyond a sight multiplier.
- **Targeting is a strong differentiator.** BannerWand's per-target model (player, clan, kingdoms, minor factions) is distinctive and worth copying for any "apply to whom" cheat.

### Gaps
- The Nexus page for Bannerlord Cheats hides its cheat list in spoilers. I used the GitHub source settings file instead, which may differ slightly from the Reload fork's current build.
- BannerWand's complete cheat list exists only in-game in MCM. My list comes from its changelog and may be incomplete; v1.0.1 mentions "74+ mod settings".
- I could not quantify "most requested" with surveys or poll data. The signals above are qualitative, drawn from comments and download counts.
- I found no dedicated mod for full map fog-of-war removal, nor for renaming parties.

## Q3. How do mods expose features (MCM, hotkeys, console, Gauntlet panels, campaign menus), and which UI approach do users prefer?

### Takeaway
Five UI patterns coexist:
1. **MCM settings pages**: Cheats, Cheats Reload, BannerWand, Faster Time, No Aging, DCC.
2. **Context hotkeys on native screens**: Cheats (Ctrl+X/H/F/G on the inventory, party, clan, character and encyclopedia screens).
3. **Buttons injected into native Gauntlet screens**: Character Reload and DCC on encyclopedia pages, Character Development Editor on the character screen, Oh The Settlements in the settlement menu, Renamer as a dialogue option.
4. **Console commands**: BLGM.
5. **A standalone Gauntlet overlay**: Commander (Ctrl+C).

Persistent rule changes go to MCM; one-off edits go to a GUI or contextual button. The download-heavy mods use MCM (rules) and in-context buttons (edits). BLGM's own author says to use the Commander GUI "without having to use console commands". I found no formal survey of preferences.

### Cited Findings
- **MCM, per campaign.** Cheats uses `AttributePerCampaignSettings` from MCM, so settings are saved per campaign.
  - Settings appear only in-campaign under Options → Mod Options → Cheats.
  - "All options are instantly applied without a restart".
  - Known quirk: after starting a new campaign the cheats may not show up until you save, return to the menu and reload.
  - [GitHub settings](https://raw.githubusercontent.com/welles/BannerlordCheats/stable/Settings/BannerlordCheatsPerCampaignSettings.cs); [Nexus 1839](https://www.nexusmods.com/mountandblade2bannerlord/mods/1839)
- **Cheats hotkeys.** They are context-bound to native screens (inventory, clan, encyclopedia, party, character), can be toggled in MCM ("EnableHotkeys"), and show hotkey tips. — [GitHub hotkeys](https://raw.githubusercontent.com/welles/BannerlordCheats/stable/hotkeys.txt); [GitHub settings](https://raw.githubusercontent.com/welles/BannerlordCheats/stable/Settings/BannerlordCheatsPerCampaignSettings.cs)
- **Cheats and vanilla cheat mode.** The cheats "work even if you do not have cheat mode enabled". Vanilla cheat mode is still needed for item spawning and slow-motion. — [Nexus 1839](https://www.nexusmods.com/mountandblade2bannerlord/mods/1839)
- **BannerWand.** "configured entirely through MCM", with every option described there. v1.1.1.1 merged "the mod's two separate settings pages ... into one", reorganized into clearer categories, and added a rebindable Add Gold hotkey. — [Nexus 9151](https://www.nexusmods.com/mountandblade2bannerlord/mods/9151); [Nexus 9151 logs](https://www.nexusmods.com/mountandblade2bannerlord/mods/9151?tab=logs)
- **Character Reload.** Adds buttons to Encyclopedia hero, clan and settlement pages. These open native screens:
  - FaceGen
  - inventory with all items
  - party with all units
  - town management
  - a custom EditHero window with tabs and hero templates
  - Value entry uses popup dialogs. Changing a name shows the popup twice because of the `_firstName`/`_name` fields.
  - [Nexus 3700](https://www.nexusmods.com/mountandblade2bannerlord/mods/3700)
- **DCC.** Puts an "Edit Appearance" button at the top of hero and troop encyclopedia pages (press N on the campaign map, pick a hero). Settings are in MCM. — [Nexus 118](https://www.nexusmods.com/mountandblade2bannerlord/mods/118)
- **BLGM.** Uses the console (Alt+~) with discoverable commands:
  - Typing `gm.` lists the categories.
  - Running a command with no args shows its help.
  - Arguments can be positional or named, and names with spaces use single quotes.
  - Some commands open native UIs, such as the face generator, inventory, party editor and banner editor.
  - [Nexus 9448](https://www.nexusmods.com/mountandblade2bannerlord/mods/9448); [BLGM wiki](https://github.com/SolWayward/Bannerlord.GameMaster/wiki)
- **Commander.** A custom Gauntlet GUI opened with Ctrl+C on the campaign map; the hotkey is configurable in its own settings UI.
  - If the hotkey fails to open it, use the console command `gm.commander.open`.
  - World-map right-click overlays issue party orders.
  - The BLGM page "Highly recommended" Commander so users can do most BLGM functions "without having to use console commands".
  - [Nexus 10127](https://www.nexusmods.com/mountandblade2bannerlord/mods/10127); [Nexus 9448](https://www.nexusmods.com/mountandblade2bannerlord/mods/9448)
- **Character Development Editor.** Pitched as "modify characters without having to use cheat codes and without having to leave the game ... straight from the character screen". — [Nexus 9953](https://www.nexusmods.com/mountandblade2bannerlord/mods/9953)
- **Campaign menu and dialogue.**
  - Oh The Settlements You'll Rename adds a "Rename Settlement" button to the settlement menu. — [Nexus 12507](https://www.nexusmods.com/mountandblade2bannerlord/mods/12507)
  - Renamer adds a [Rename] dialogue option. — [Nexus 8372](https://www.nexusmods.com/mountandblade2bannerlord/mods/8372)
  - Older editors used global hotkeys to open a full editor: EditLord (Alt+E) and CITEditor (Ctrl+Alt+E). — [Nexus editor search](https://www.nexusmods.com/games/mountandblade2bannerlord/mods?keyword=editor&sort=endorsements)
- **Map hotkeys for teleport.** Ctrl+LMB (vanilla and 10006), Ctrl+Alt+LMB (10005), Ctrl+Shift+Click (Get Over Here). — [Nexus teleport search](https://www.nexusmods.com/games/mountandblade2bannerlord/mods?keyword=teleport&sort=endorsements)
- **Time control in MCM.** Faster Time keeps vanilla keys and buttons ("Same keys, same buttons, nothing new to learn") and adds one MCM slider plus a toggle. — [Nexus 11712](https://www.nexusmods.com/mountandblade2bannerlord/mods/11712)

### Inferences
- **Recommended hybrid UI** for an all-in-one mod:
  - **MCM** for persistent rules and multipliers, per campaign as in Cheats.
  - **Contextual buttons and hotkeys** on native screens (encyclopedia, character, settlement menu, party, inventory) for one-off edits.
  - **One Gauntlet "editor hub" overlay** on a hotkey, Commander-style, for cross-entity edits.
  - **Console commands** as a power-user and fallback layer, BLGM-style. This also helps when a hotkey conflicts.
- Map teleport is best on a modifier+click hotkey. Ctrl+LMB collides with vanilla cheat mode, which explains why the 10005 mod uses Ctrl+Alt.
- MCM is the de-facto standard among popular mods. Depending on it is accepted but adds the dependency chain (Harmony, ButterLib, UIExtenderEx, MCM).

### Gaps
- I found no direct user poll or Reddit discussion comparing UI approaches. The preference shown here is inferred from download counts and author statements.

## Q4. What are the known problems (save corruption, crashes, incompatibilities)?

### Takeaway
The dominant problem is **breakage on every TaleWorlds patch**: crashes (CTD), features silently not working, and module-mismatch prompt loops. This comes from mods being built against specific game DLLs and Harmony patch targets. Other recurring issues:
- conflicts with overhauls such as RBM and RoT, and load-order sensitivity
- blocked DLLs
- MCM per-campaign settings not appearing
- editor actions that crash on new versions (relationship manager, resurrection)

Mods without saved state are usually safe to add or remove. Mods that create entities (new heroes, clans, kingdoms) or change names and cultures leave lasting state in the save.

### Cited Findings
- **Cheats Reload, known incompatibilities (v1.2.9.5 sticky)**: — [Nexus 6446 posts](https://www.nexusmods.com/mountandblade2bannerlord/mods/6446?tab=posts)
  - Fourberie breaks the 0% food consumption option.
  - RBM "breaks some options of this Cheat mod that affects health, and also sometimes caused CTD".
  - The author notes crash reports listing only OnTick patches are "99%" not this mod's fault.
- **Cheats Reload on 1.4.8 (user reports, Aug–Sep 2026)**: — [Nexus 6446 posts](https://www.nexusmods.com/mountandblade2bannerlord/mods/6446?tab=posts)
  - With a damage multiplier set, "the game will almost inevitably crash when attacking enemies".
  - CTD reports.
  - Item spawn "seems broken"; the fix is putting the mod at the bottom of the load order.
  - The troop menu freezes.
  - Adding the mod to an existing 1.4.8 save causes a repeating "module mismatch" prompt. Workaround: load from "Saved Games" instead of "Continue Campaign", or spam ESC.
- **Character Reload (2025–2026 posts)**: — [Nexus 3700 posts](https://www.nexusmods.com/mountandblade2bannerlord/mods/3700?tab=posts)

  - "cannot load ... CharacterReload.dll" means Windows blocked the DLL and it needs unblocking.
  - The author said the e1.3.11/1.3.13 update took "over six months" of work.
  - The author warns that the Relationship Manager has "almost no foolproofing ... save before use it".

Commander's version must match BLGM's. — [Nexus 9448](https://www.nexusmods.com/mountandblade2bannerlord/mods/9448); [Nexus 10127](https://www.nexusmods.com/mountandblade2bannerlord/mods/10127)

  - Movement speed set to "40+ instead of 16".
  - Unlimited Ammo "raising your max ammo every time it reapplies" and making shields infinite.

  - Duplicate hourly and daily application.

- **Teleport (10005).**
  - It waits a short pause to make sure the target point is set, and it "doesn't correctly teleport you to towns".
  - The author "Fixed a lot of crashes" and says "backup and cycle your save games".
  - The older Teleport Only "does not work anymore" according to its comments.
  - [Nexus 10005](https://www.nexusmods.com/mountandblade2bannerlord/mods/10005)
- **Rename persistence.**
  - Oh The Settlements You'll Rename: "To update the nameplate on the world map, make a new save and reload". If uninstalled, names revert to default. — [Nexus 12507](https://www.nexusmods.com/mountandblade2bannerlord/mods/12507)
  - BLGM: settlement `set_culture` "changes persist across save and load". — [BLGM wiki](https://github.com/SolWayward/Bannerlord.GameMaster/wiki)
- **No Aging Extended.** "Nothing in your save depends on this mod", so it is safe to add or remove. Removing it doesn't rewind ages. — [Nexus 12601](https://www.nexusmods.com/mountandblade2bannerlord/mods/12601)
- **Faster Time.** One Harmony patch that "fails soft": if a game update breaks the target, it shows a red message and falls back to vanilla instead of crashing. Known side effect: the console "campaign speed" cheat stops working while it is enabled. — [Nexus 11712](https://www.nexusmods.com/mountandblade2bannerlord/mods/11712)
- **Vanilla cheat mode.** It slows the inventory and troop sections, according to the Teleport Only author. — [Nexus teleport search](https://www.nexusmods.com/games/mountandblade2bannerlord/mods?keyword=teleport&sort=endorsements)
- **Older Character Reload builds.** A Steam discussion says it worked for a few betas, then broke around 1.8.0, with a suspected Harmony conflict (search snippet). — [Steam discussion (via search)](https://steamcommunity.com/app/261550/discussions/0/3712685279012918498)
- **Bannerlord Cheats on 1.3 (Steam comments, via search snippet).** Commenters reported it not working on 1.3.1 and needing the MCM beta. — [Steam discussion](https://steamcommunity.com/workshop/filedetails/discussion/2882183897/4035854109134667344)

### Inferences
Design lessons for the all-in-one mod:
- **Isolate each Harmony patch** with fail-soft registration, as Faster Time does. Audit targets against the installed game DLLs, as UFO's `HarmonyApiAudit` tool does.
- **Clamp and auto-reset dangerous values**, as BannerWand does.
- **Avoid hourly or daily re-application side effects.**
- **Keep persistent save state minimal.** Store renames, custom names and age locks in a separate, versioned save-data container so that removing the mod degrades gracefully.
- **Treat high-risk editor actions as crash-prone** after patches: resurrect, relationship transfer, kingdom/clan transfer, banner edits. These need validation and a "save before" prompt.

### Gaps
- I found no specific, confirmed save-corruption cases from 2026 that were tied to a named cheat mod, only crashes and non-persistence. Older save-corruption anecdotes (for example kill/resurrect, or removing mods that created heroes) were not verified in this research.
- I did not read BLGM's or Commander's bug and forum tabs.

## Q5. Are any of these open source (GitHub) so their implementation can be referenced?

### Takeaway
Yes. The most useful references are:
- **welles/BannerlordCheats** (MIT; Harmony patches + MCM per-campaign settings + screen hotkeys)

### Inferences
- For an all-in-one mod:
